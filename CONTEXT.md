# Daybook: project context (for ChatGPT / any AI assistant)

Paste this whole file into a chat before asking questions or requesting changes.

## 1. What it is
Daybook is a **3D study-room journaling app** in a single, self-contained web page (`index.html`, about 370 KB). The user sits in a rendered 3D study with a desk, lamp, window, wall clock and bookshelf. Each journal is a physical book on the shelf. You take one down, open it, and write in it with a choice of pens. Ink appears as if the pen is writing it.

- No framework, no backend and no runtime packages: plain HTML, CSS and vanilla JS (about 4,900 lines of JS in `src/`). Python 3 runs the build; Node and `playwright-core` are only needed for the tests.
- Loaded from CDNs at runtime: **three.js r128** (cdnjs) for the 3D room, and **Google Fonts** (Cormorant Garamond, Pinyon Script, Caveat, Kalam, Patrick Hand, Reenie Beanie, Nanum Brush Script, Dancing Script, Homemade Apple, Special Elite, Manrope). It needs internet to run.
- It was built to run as a Claude Artifact. Inside Claude it saves through `window.claude` (the `db`, `user` and `downloads` capabilities). Anywhere else it falls back to `localStorage`.

## 2. Folder layout and build
```
daybook-source/
├── index.html    The built page. Generated by build.py; do not edit it by hand.
├── build.py      Builds index.html from src/.
├── README.md     Short build and test notes.
├── CONTEXT.md    This file.
├── src/          The source, in build order:
│   ├── p1_css_a.html, p2_css_b.html   Page head (title, fonts) and all styles
│   ├── p3_body.html                   Markup: HUD, room bars (tour, peek, explore, arrange), library drawer,
│   │                                  reader, cover studio, room customizer, welcome, lock screen
│   └── j1 … j12 (.js)                 Scripts
└── tests/        Browser tests (Playwright driving Google Chrome)
```
**Build:** `python3 build.py` writes `index.html` as `p1 + p2 + p3`, then the three.js r128 `<script>` tag, then one `<script>` that wraps all the scripts in a single `(function () { 'use strict'; … })();`. Running it twice produces a byte-identical file.
**Script order:** `j1_core → j2_paint → j3_data → j4_room → j5_room_actions → j6_reader → j7_decor → j8_pops → j9_studio → j10_library → j12_turn → j11_boot`. Note that j12 comes before j11. Everything shares one closure scope, so there are no imports or exports.

## 3. Features

### The 3D room
- Tap a book on the shelf to take it to the desk, and tap it again to open it; the camera moves to the desk first. Escape cancels while it moves.
- **HUD:** Write today, Library, Tour, Explore, Customize, New journal, lamp, day/night, sounds, and a lock button once a PIN is set.
- **Guided tour:** 6 stops (Desk & Journal, Bookshelf, Window & Skyline, Wall Clock, Desk Lamp, Study Keepsakes). A bar at the bottom shows the stop's name and description, "Stop 2 of 6", Previous and Next (Previous is disabled on the first stop; Next becomes Finish on the last), dots to jump to a stop, and Exit tour. The arrow keys and Escape work too, but only while nothing else (library, sounds panel, a dialog) is open on top. Starting free explore, looking outside, arranging, customizing or opening a journal ends the tour. The Tour button stays in the header on phones (icon only, named "Room tour").
- **Free explore:** drag to look, W/A/S/D or arrow keys to move, a speed slider, Escape to leave.
- **Look outside:** the camera glides up to the window and frames the painted sky and skyline (clouds by day, moon, stars and lit windows at night, rain when it rains). Drawn curtains part for the view without changing the saved setting. Return to study (or Escape) goes back to the view the visitor had; starting it from free explore leaves explore first.
- **Clickable objects:** lamp (on/off), window (open/close, look outside, curtains, styles), curtains, clock (customize, display mode, second hand), radio (next ambience, sounds panel, arrange), pen cup (choose a pen, arrange), plant (pot style, arrange, visibility), mug, globe (spin, arrange, customize), wall art (next style, customizer), shelf (library), desk.
- **Arrange mode:** drag desk objects, rotate them (buttons or `[` `]`), reset one (button or `R`) or all, then Done or Escape. The layout is saved.
- **Room customizer** (6 tabs): Presets; Walls & Floor (8 wall colours, 5 woods); Furniture & Objects (3 wood finishes, 4 lamp styles, 4 pot styles, 4 wall-art styles, which decorations to show, arrange mode); Lighting & Weather (weather, sync sky with local time, day/night, desk lamp, 4 light temperatures); Window & Curtains (open or close the window and curtains, 5 curtain fabrics, look outside); Clock (show/hide, 4 faces, analog/digital/both, second hand).
- **Presets:** 5 starter presets (Cozy Night, Rainy Evening, Morning Focus, Warm Library, Minimal Study) and custom presets saved from the current room. Custom presets can be applied, renamed and deleted; rename and delete ask inside the preset card, not in a browser dialog.
- **Weather:** Clear Sky, Gentle Rain (rain falls in the window and the sky dims), Drifting Clouds (the sky dims; there is no cloud layer), Starry Twilight (forces night; choosing daytime ends it). Weather can only darken the day/night setting, never lighten it.
- **Sky:** follow my clock (rechecked every 30 seconds while the page is open), always day, or always night.
- **Reduced motion** is respected: camera moves, book moves, rain and sky fades become instant or still.
- Fallback: a `no3d` body class for devices that cannot do WebGL.

### Writing
- **9 pens:** Fountain, Ballpoint, Gel, Pencil, Felt marker, Brush pen, Calligraphy, Feather quill, Typewriter. Each has its own handwriting font, size and sound.
- **12 inks**, including white, gold and silver gel pens for dark paper.
- **Animated ink:** words appear as if written, with a small pen drawn at the caret. This can be turned off.
- **Paper:** 10 colours (Fresh white, Ivory, Old parchment, Brown kraft, Rose, Sky blue, Mint, Lavender, Butter yellow, Midnight black). Rulings are Lined, Dotted, Grid or Blank. Text size is Small, Medium or Large. Paper textures are generated procedurally.
- **Per-journal defaults** for paper, ruling, pen, ink and scale, with an option to apply a page's style to the whole journal.
- **10 templates** (Daily reflection, Gratitude, Morning pages, Dream log, Travel day, Weekly review, To-do list, Letter to future me, Mood check-in, Book notes) and **20 writing prompts**.
- **Mood tracking** per page on a 5-level scale (Rough, Low, Okay, Good, Great).
- **#tags** inside text, which become clickable search chips.
- A daily **word-goal ring** in the reader.
- Up to **999 pages** per journal. Page numbers can be reached with a go-to field and slider.
- **Bookmarks** with 8 colours and a label (for example "Trip to Goa"), shown as ribbons.

### Scrapbooking a page
- Photos (compressed and stored with the journal), emoji **stickers** (56), **washi tape** (8 patterns), and notes.
- Freehand **doodle** and **highlighter** (5 colours) drawing directly on pages, with a draw toolbar.
- A page that holds too much drawing data is blocked from saving (about 245 KB per page cap), with a message.

### Cover studio (design your own journal)
- Cover colour (16), material (Leather, Linen, Velvet, Kraft card, Marbled, Canvas), pattern (Frame, Corners, Band, Stripes, Dots, Stars, Waves), emblem (Moon, Sun, Star, Heart, Leaf, Flower, Feather, Compass, Mountain), foil (Gold, Silver, Copper, Rose gold, Black ink, Cream).
- Title font (Classic, Script, Handwritten, Modern, Typewriter), plus free-form layers on the cover: drawing, photos, text boxes (8 fonts) and stickers.
- Book size (Pocket, A5, Tall), thickness (Slim, Regular, Thick) and ribbon colour. The spine is drawn too.
- Starter journals: **Daily Journal, Gratitude, Dreams, Notes & Ideas**.

### Page turning
- A real curling sheet that follows a finger. Mouse users drag a page corner. Arrow keys also work.
- Settings for speed (Slow and gentle, Natural, Quick) and paper curl on/off.

### Library drawer (4 tabs)
1. **Journals:** summary stats (journals, pages, words, day streak), "On this day" memory cards (entries from past months or years on today's date), **search across all journals**, top tags, and the journal list with covers.
2. **Calendar:** month view of the days written. Selecting a day shows that day's entries.
3. **Insights:** an 18-week writing heatmap, a 30-day mood chart, when you write, top tags, and **12 badges** (First page, 3-day streak, One week, One month, 1,000 words, 10,000 words, 25 pages, Cover artist, Scrapbooker, Night owl, Early bird, Collector). Streak milestones (3, 7, 14, 30, 50, 100, 200, 365) trigger confetti.
4. **Settings:** daily word goal, animated pen, pen sounds, sky mode, a shortcut to the room customizer, wall colour, wood, lamp light, curtain fabric, page turning, PIN lock, export, replay welcome tips.

### Sound (all generated with the Web Audio API)
- **Ambience:** Quiet, Rain on the window, Crackling fireplace, Ocean waves, Summer night (crickets), Café murmur. Switching fades and crossfades instead of cutting.
- The **Volume** slider in the sounds panel sets both ambience and pen sounds.
- The chosen ambience is saved. After a reload it starts on the first click or key, because browsers block sound before the visitor interacts. Ambience pauses while the tab is hidden and resumes on return.
- The weather suggests a matching ambience (Gentle Rain → Rain on the window, Starry Twilight → Summer night) in a toast and in the Lighting & Weather tab, but never changes it on its own.
- **Pen sounds:** scratch, smooth, pencil, felt and typewriter clack, plus page flips and clicks.

### Privacy and security
- **PIN lock:** 4 to 6 digits, stored as a hash (`pinHash`) with an optional hint. It asks for the PIN on open and after 3 minutes away, and has a manual "Lock now". Digits, Backspace and Enter work from the keyboard. This is a casual privacy feature, not strong encryption.
- Inside Claude, journals are stored per user under `data/users/<uid>/lib` and are only readable by that user.

### Data and export
- **Export** a single journal or all journals as Markdown (`.md`), including page numbers, dates and moods. Inside Claude it goes through Claude's downloads; anywhere else it is an ordinary browser download.
- Imports entries from an older "daybook:v1" data format into the first journal.
- Welcome dialog for new users with 4 quick tips. It does not pop up over a journal or panel the visitor has already opened, and its last line says where journals are kept (this browser, or the Claude account).
- Accessibility basics are present: ARIA roles and labels, `aria-live` toasts, dialog roles, keyboard support.

## 4. Data model (in `j3_data.js`)
- `state = { lib, pages: Map, store, ready }`
- **`lib`** (version 4): `{ v:4, journals:[…], activeId, settings:{…} }`
  - Journal: `{ id, title, subtitle, order, created, size, thick, ribbon, pages(count), bookmarks:[{n,color,label}], last, cover:{color,material,pattern,emblem,foil,font}, defaults:{paper,ruling,pen,ink,scale}, art:{hideTitle,layers:[]} }`
  - Settings defaults (`SETTINGS_DEFAULT`): `sky:'auto', lamp:true, goal:250, animate:true, penSound:true, volume:.6, pinHash:null, pinHint:'', welcomed:false, goalDay:'', celebrated:0, ambient:'off', turnSpeed:'normal', curl:true, wall:'sage', wood:'walnut', lampTone:'warm', windowOpen:false, curtainsOpen:true, curtainColor:'ochre', showClock:true, clockMode:'analog', clockStyle:'daybook', clockSec:true, clockTick:false, weather:'clear', woodFinish:'satin', lampStyle:'brass', artStyle:'quiet_focus', potStyle:'terracotta', globeStyle:'brass', radioStyle:'wood', exploreSpeed:1, activePreset:'default', customPresets:{}, objectLayout:{}, visibleObjects:{globe,plant,radio,cup,mug,art,clock}`
  - `customPresets` is an object keyed by preset id: `{ [id]: { id, name, desc, wall, wood, woodFinish, lampTone, lampStyle, lamp, potStyle, artStyle, weather, sky, windowOpen, curtainsOpen, curtainColor, clockStyle, clockMode, showClock, visibleObjects, objectLayout } }`. On load, `normPresets` turns older arrays into this form, drops entries that are not objects, and gives nameless presets a default name.
  - `objectLayout`: `{ [objectId]: { x, y, z, rotY } }` for objects moved in arrange mode.
- **Page**, keyed `"<journalId>~<pageNumber>"`: `{ j, n, text, date (YYYY-MM-DD), mood (0–5), style?, items?[], ink?[], updatedAt }`. Empty pages are deleted, not stored.
- **Media:** photos are stored separately by id.
- **Storage adapters** share one interface: `init`, `subscribe`, `writeLib`, `writePage`, `writeMedia`, `readMedia`, `deleteMedia`.
  - `cloudStore` uses `window.claude.use('db')` with real-time snapshots, so multiple tabs and devices stay in sync.
  - `localStore` uses localStorage keys `daybook3d:v1` (shape `{ lib, pages }`) and `daybook3d:m:<id>`. Every save re-reads what is stored and changes only its own part (the library, or one page), and other tabs' saves arrive through the `storage` event into the same merge the cloud store uses, so two open tabs never erase each other's journals or pages.
- **Saving:** the library is debounced by 350 ms and pages by 700 ms, through a serial promise queue, and everything is flushed when the page is hidden or closed. Remote updates never overwrite a page that has unsaved local edits. Save failures show a toast and "Not saved yet"; when browser storage is full (about 5 MB) or blocked, the toast says so in plain words, and a photo that cannot be stored is refused instead of disappearing on reload.

## 5. Conventions in the code
- Vanilla JS, `'use strict'`, one IIFE closure, `const`/arrow functions, compact one-line functions.
- DOM is built with a small hyperscript helper `h(tag, attrs, ...children)` plus `$`/`$$` selectors.
- Panels are shown and hidden with the `hidden` attribute (or `.hidden` property). `p1_css_a.html` has `[hidden] { display: none !important; }` so that wins over component rules like `.lock { display: grid }`.
- No native `alert`/`confirm`/`prompt`: they are blocked in sandboxed frames, so confirmations are inline (see journal delete and custom presets).
- Comments are section banners (`/* ==== */`) and short notes on non-obvious lines. No TypeScript.
- `window.Daybook` exposes internals (`state`, `R3`, `S()`, `SND`, `openJournal`, `applyPreset`, `openRoomCustom`, …) for the tests and for debugging in the console.

## 6. Things to know before changing it
- Edit `src/`, then run `python3 build.py`. `index.html` is overwritten by every build.
- **Catalogue shapes differ.** `WALLS`, `WOODS`, `LAMPS` and `CURTAIN_COLORS` entries are arrays (`[name, colour, …]`). `CLOCK_STYLES`, `LAMP_STYLES`, `ART_STYLES`, `WEATHER_MODES` and `MOVABLE_OBJECTS` entries are objects with a `name`. `FINISH_STYLES` and `POT_STYLES` use `rough`/`metal`, and `TOUR_STOPS` uses `label`/`pos`/`target`, plus an optional `portrait: { pos, target }` that tall screens (width/height under 0.85) use instead. Reading the wrong field gives `undefined`, which earlier rendered shelves and curtains black and crashed the tour.
- Cover and page art is canvas-drawn. 3D textures come from canvases too, so wall, wood and curtain colours are redrawn into textures when they change.
- Page JSON is capped at roughly 245,000 characters, and photos are compressed to stay under storage limits.
- The `window.claude` APIs (`use('db')`, `use('user')`, `use('downloads')`) exist only in Claude. Outside it, journals are kept in the browser and export falls back to a normal download.
- To run locally, open `index.html` in a browser with internet access. No server is needed. Hosted as a website it is one static file; serve it over HTTPS.
- **Keep the head at the top of `p1_css_a.html`:** `<!doctype html>` (without it browsers use quirks mode), `<html lang="en">`, `<meta charset="utf-8">` (it must stay within the first 1024 bytes) and `<meta name="viewport">` (without it phones lay the page out at 980 px and zoom out, so none of the phone styles apply). Many servers send `text/html` with no charset; without the charset tag, browsers read the page as windows-1252, so "Pages 1–2" shows as "Pages 1â€“2" and symbols the app inserts (template boxes, stickers) are saved garbled. `build.py` reads and writes UTF-8 explicitly.
- **Tests** (`tests/`, need `npm i playwright-core`, Google Chrome and internet; rebuild first):
  - `node tests/test_transitions.mjs`: room-to-journal transitions, Escape, rapid clicks, reduced motion, unsaved text, closing while the cover is still opening, looking out of the window (real pixels of the view by day and night, the view given back, drawn curtains, leaving explore), object pop-ups placed beside the object, and emoji kept whole by the animated ink.
  - `node tests/test_weather_audio.mjs`: weather states, rain, sky sync, ambience fades, volume, autoplay restrictions, hidden tab, persistence.
  - `node tests/test_stability.mjs`: real rendered colours of shelves, desk, pots and curtains; hidden panels; PIN lock; custom preset create/apply/rename/delete; legacy or malformed preset data; starter preset values; text and saved symbols when a server sends no charset; the page head; the library after writing (#tags) and from the shelf; two open tabs; full browser storage; export as a download; the welcome not covering an open journal; customizer layout and tap-target sizes.
  - `node tests/test_tour.mjs`: the tour bar: start, progress, Previous/Next, first and last stops, Finish, Exit tour, Escape, focus, keys while other panels are open, cancellation by other modes, reduced motion, the phone header at 390 and 320 px, that Study Keepsakes frames the globe, plant and radio at desktop and phone sizes, and that the Window & Skyline stop shows the night sky through both panes. `test_stability.mjs` also takes `CPU_THROTTLE=n` to slow the page's CPU while hunting flaky timing.
  - Pass a path to test another build, and `ONLY="part of a test name"` to run a subset. Rendering is software WebGL in headless Chrome, so the tests wait on state rather than fixed delays.
- **Known gaps:** Drifting Clouds only dims the sky; Starry Twilight looks the same as a clear night; changes synced from another tab or device are stored but the room and sound do not re-apply them until reload; `globeStyle`, `radioStyle` and `clockTick` are stored settings with no control; tour stops assume the default desk layout, so moving objects in arrange mode can take them out of a stop's frame; on portrait phones and tablets the room view shows only the middle of the room (the window, clock, wall art and pen cup are off-screen), and at 460 px or narrower the header drops Customize, Explore, New journal, lamp and sky, so those are reached through the Library (Settings has "Customize 3D room", which also leads to Look outside under Window & Curtains); the peek bar's label wraps one word per line on phones; at 320 px the page date is shortened ("Wed, 2…").
- **Older entries may hold garbled symbols.** Before the charset fix, a page served without a charset saved app-inserted symbols garbled: the To-do template's boxes as `â˜` and stickers (page and cover) like `ðŸŒ™`. Text the visitor typed was never affected. Nothing repairs these automatically.
- **Unresolved:** once, in a full run of `test_stability.mjs`, a custom preset saved immediately before a page reload was missing after the reload. It has not reproduced since (more than 53 later attempts, including CPU-throttled and parallel runs), so the cause is unknown and it is **not fixed**. If it recurs, that test reports the stage where the preset was lost: A (never saved in memory), B (the test's seed re-ran), C (never written to storage), D (in storage but dropped while loading).
